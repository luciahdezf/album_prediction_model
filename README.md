# Music Release Prediction Dashboard

## Descripción

Este proyecto consiste en el desarrollo de una aplicación interactiva para analizar y predecir el rendimiento de lanzamientos musicales.

La aplicación combinará información histórica de artistas y lanzamientos con datos de consumo y popularidad para estimar el rendimiento esperado antes de la publicación. Una vez producido el lanzamiento, se incorporarán nuevos datos reales para analizar su evolución y actualizar progresivamente las predicciones iniciales.

Los resultados se presentarán mediante visualizaciones interactivas que permitan comparar las estimaciones con el comportamiento real del lanzamiento.

## Objetivos

- Integrar y procesar distintas fuentes de datos musicales.
- Predecir los streams esperados de un lanzamiento antes de su publicación.
- Analizar la evolución del consumo durante los primeros días, semanas y meses.
- Actualizar las predicciones iniciales a medida que se incorporen nuevos datos.
- Identificar las variables que más influyen en el rendimiento esperado.
- Desarrollar una aplicación interactiva con Dash y Plotly para visualizar los resultados.

## Plan de trabajo inicial

1. **Adquisición y preparación de datos:** recopilación, integración, limpieza y transformación de las distintas fuentes.
2. **Análisis y feature engineering:** exploración de los datos y construcción de las variables necesarias para los modelos.
3. **Modelado predictivo:** desarrollo, comparación y evaluación de modelos pre-release y post-release.
4. **Visualización:** creación de gráficos interactivos para representar predicciones, datos reales y evolución temporal.
5. **Desarrollo de la aplicación:** integración de los modelos y visualizaciones mediante Dash.
6. **Despliegue y mejora:** publicación de la aplicación y desarrollo progresivo de nuevas funcionalidades.
